# Esonero Reti di Calcolatori a.a. 2026-27 - I Assegnazione (Socket TCP)

- **Gruppo:** G13
- **Componenti:** Palmieri Davide (865810), Lusha Endri (865525)
- **Sistema Operativo utilizzato:** Windows 11 (oppure Linux Ubuntu 24.04 / macOS)
- **Ambiente di sviluppo:** Eclipse IDE for C/C++ Developers

## Struttura dei progetti
- `serverTCP_G13`: applicazione server iterativa in ascolto su porta TCP (default `5193` o passata da riga di comando).
- `clientTCP_G13`: applicazione client che legge IP, porta e terne di interi da standard input.
